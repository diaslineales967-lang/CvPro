# 📄 CV Express IA | Generador Automático de Currículums

Plataforma web moderna y automatizada para la creación de currículums profesionales optimizados para los filtros ATS de portales de empleo como **Computrabajo** y **Bumeran**. Diseñada especialmente para el mercado de Perú, permitiendo pagos rápidos mediante **Yape**, **Plin** o Tarjeta.

---

## ✨ Características Principales

* **Selección de Plantillas:** Elige entre modelos modernos, minimalistas y de alto impacto visual.
* **Optimización con IA (Simulada):** Estructura y reescribe los datos del usuario para destacar palabras clave de puestos de trabajo (Atención al cliente, call center, ventas, etc.).
* **Pasarela de Pagos Local:** Integración visual y simulada para cobros instantáneos mediante **Yape**, **Plin** y tarjetas de débito/crédito (S/ 4.50).
* **Descarga Instantánea:** Generación y descarga directa del CV en formato **PDF** lista para postular.
* **100% Responsivo:** Adaptado perfectamente para celulares y computadoras.

---

## 🚀 Tecnologías Utilizadas

* **HTML5 & CSS3** (Estructura y diseño moderno)
* **Tailwind CSS** (Framework de estilos)
* **JavaScript (Vanilla)** (Lógica de pasos, pagos y simulación de IA)
* **jsPDF** (Generación de documentos PDF directamente en el navegador)
* **FontAwesome** (Iconografía moderna)

---

## 🛠️ Cómo instalarlo y probarlo localmente

1. Clona este repositorio o descarga el archivo principal.
2. Asegúrate de que el archivo principal se llame `index.html`.
3. Ábrelo directamente en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Brave, etc.).

---

## 🌐 Despliegue en GitHub Pages

Puedes publicar este proyecto de forma gratuita en la web siguiendo estos pasos:
1. Sube tu archivo `index.html` a tu repositorio en GitHub.
2. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección *Branch*, selecciona la rama `main` (o `master`) y haz clic en **Save**.
5. ¡Listo! GitHub te dará un enlace público para que tus clientes puedan entrar a crear y descargar sus CVs.
